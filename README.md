# 🚖 Uber Ride Booking & Business Performance Dashboard | Power BI
Developed an interactive Power BI dashboard to analyze Uber ride bookings, revenue trends, vehicle performance, customer behavior, and business insights using data visualization and DAX.

# 📌 Project Overview
This project focuses on analyzing Uber ride booking data using Microsoft Power BI to transform raw data into meaningful business insights.

The dashboard provides a comprehensive view of booking performance, revenue generation, vehicle performance, customer behavior, and location-based trends through interactive visualizations and analytical reports.

The objective is to help businesses understand booking patterns, monitor performance, identify trends, and make data-driven decisions.

# 🎯 Project Objectives
Analyze overall Uber ride booking performance.

Monitor revenue generation and booking trends.

Evaluate vehicle-wise booking performance.

Understand customer booking behavior.

Identify peak booking periods and location-based trends.

Track successful, cancelled, and incomplete bookings.

Present actionable business insights through an interactive dashboard.

# 📊 Key Performance Indicators (KPIs)

The dashboard focuses on the following business metrics:

Total Bookings

Successful Bookings

Cancelled Bookings

Booking Revenue

Average Booking Value

# 🔍 Key Business Insights

The dashboard helps identify:

Booking trends and changes in ride demand.

Revenue contribution across different vehicle categories.

Successful versus cancelled booking patterns.

Customer booking preferences.

High-demand pickup and drop-off locations.

Opportunities to improve operational performance.
